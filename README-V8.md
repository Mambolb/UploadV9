## GitHub Desktop update
1. In GitHub Desktop select WebPrototypeUploadFolder, Repository > Show in Finder.
2. Back up the folder.
3. Unzip the UPDATE archive and copy its contents into the repository root, replacing existing files. Do not overwrite .git.
4. Commit to main and Push origin.
5. Hard-refresh your site (Cmd+Shift+R).
